# robb3n 的 DSH 插件

在 DeepSeek Harness 启用「自定义插件索引」，然后到「插件 → 发现 → 添加索引源」粘贴订阅地址。这个公开索引和其中的插件均可匿名读取。

```text
https://raw.githubusercontent.com/robb3n/dsh-plugins/main/index.json
```

| 插件 | 用途 |
|---|---|
| [Chrome DevTools](https://github.com/robb3n/dsh-plugin-chrome-devtools) | 在 DSH 会话里查看与操作独立 Chrome 实例的页面。 |

每个版本在 `index.json` 中固定到插件仓的完整 Git 提交。刷新「发现」即可查看可用版本。
